1. Discover a capability

An LLM watches the live app and works out how to accomplish a goal, step by step. This only needs to happen once per capability — after this, replay does it deterministically, with no model involved.

Escalation (human takeover if the agent gets stuck) is CLI-only for now — see the terminal command shown after a stuck run.

2. Capabilities

Every discovery run compiles into one of these — a typed, reviewable contract an AI agent (or you) can invoke by name, with declared inputs, outputs, and a success condition.

3. Replay a capability

Deterministic. No LLM involved. Same inputs always produce the same steps.

4. Evidence — every run, in plain language

Discovery and replay runs both leave a full trail: what happened, why, and what the result was. Click a run to see the step-by-step story.
